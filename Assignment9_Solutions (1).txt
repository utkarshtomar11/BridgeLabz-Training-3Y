      <h1>Fluid Typography with clamp()</h1>
      <p>
        This paragraph demonstrates responsive typography using the
        CSS clamp() function. The font size automatically scales
        between a minimum and maximum value based on the viewport
        width, ensuring readable text on every screen size without
        needing multiple media queries just for font sizing.
      </p>
    </section>
  </main>

---------------- FILE: q4.css ----------------

}

  max-width: 800px;
  margin: 0 auto;
  padding: 3rem 1.5rem;
  text-align: center;
}

  font-size: clamp(1.5rem, 4vw, 3rem);
  margin-bottom: 1rem;
  color: #333;
}

  font-size: clamp(1rem, 2vw, 1.5rem);
